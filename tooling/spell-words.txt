# Project dictionary for the spell-check gate (`python3 -m tooling.spell`).
#
# One word per line. Lines starting with `#` are comments. cspell splits
# camelCase and PascalCase identifiers into their parts, so `SignalKit` or
# `GetTimePreciseSec` never needs an entry; only all-lowercase run-together
# names and genuine domain terms do.
#
# Rule for adding a word: it must be spelled correctly, it must be a name or a
# term the documentation uses on purpose, and it goes under the heading that
# says why it is here. A typo is fixed in the document, never added here.
# cspell is configured for English with British spellings (`en,en-GB` in
# cspell.json) because the documentation uses them, so British forms such as
# "behaviour" and "licence" are not listed.
