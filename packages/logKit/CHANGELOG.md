# Changelog

## 0.1.0 — 2026-09-24

- Added LogKit API generation 1, implementation revision 1: levelled logging with per-addon loggers, lazy secret-safe formatting, a tri-state level, a bounded journal built on SignalKit's journal, and sinks.
- Added `LogKit.LEVELS`, a read-only table of the level ordering (`trace` 1, `debug` 2, `info` 3, `warn` 4, `error` 5, `off` 6), and `LogKit.DEFAULT_LEVEL` (`"warn"`).
- Added `LogKit:ForAddon(addonName)`, one memoised logger per addon name, bounded by `maxLoggers` (256; `nil, "capped"` beyond it).
- Added the logger methods `Trace`, `Debug`, `Info`, `Warn` and `Error(message, ...)`, plus `Log(level, message, ...)`, `IsEnabled(level)`, `SetLevel(level|nil)`, `GetLevel()` (the effective level and its source, `"addon"`, `"global"` or `"default"`) and `GetAddonName()`. A disabled call costs a receiver check and one comparison and never reads the message or its arguments; an enabled call formats with `string.format` only when arguments are present, so a bare message keeps its `%` characters. Arguments that are not strings or numbers are converted with `tostring` before `string.format`, so `%s` formats `nil`, booleans and tables as Lua 5.2 does.
- Format arguments that are secret values are replaced by `LogKit.SECRET_PLACEHOLDER` (`"<secret>"`) before formatting; a secret message, addon name, level, sink or chat frame is refused at the caller; `RemoveSink` answers `false` for a secret handle like any unknown value. A bad format string is reported through the host error handler and the message is dropped; the call never raises. At most `MAX_FORMAT_ARGUMENTS` (16) arguments per call.
- Added `LogKit:SetGlobalLevel(level|nil)` and `LogKit:GetGlobalLevel()`. Precedence: addon override, then global level, then the default. A setter repeating the level in force changes nothing and writes nothing.
- Added `LogKit:AddSink(sink)` for a function `(record)` or a table with `Write(record)`, returning a handle for `LogKit:RemoveSink(handle)`; bounded by `maxSinks` (16; `nil, "full"` beyond it). The record `{ addon, level, levelName, message, time }` is one reused table, valid during the call. A table sink's `Write` is looked up at every call. A failing sink is reported through the host error handler and the other sinks still run; an error handler that raises falls back to `print` and never reaches the logging caller; a message logged from inside a sink is journaled but not delivered to sinks. A journal firing SignalKit refuses (its `maxJournalArguments` lowered below 4) is reported and the message still reaches the sinks.
- Added `LogKit:ChatSink(chatFrame?)`, printing `[addon] level: message` with the level coloured through `chatFrame:AddMessage`, `DEFAULT_CHAT_FRAME` read per line, or `print`.
- Added `LogKit:History(addonName?, minimumLevel?)`, an allocation-free walk over the journal oldest to newest yielding `(position, addon, levelName, message, time)`, filtered by addon and level.
- Added `LogKit:RegisterCommand()`, registering `/log <addon|*> <level|default>` and `/log show [addon]` through CommandKit API 1 when it is loaded (`false, "absent"` otherwise, `false, "unavailable"` without `SlashCmdList`). The level word is read without case, extra tokens are ignored, and setting an addon's level never creates its logger.
- Added `LogKit:BindLevels(db)`, persisting addon overrides and the global level in a SettingsKit API 1 database whose `global` scope declares `logLevels`, restoring them on bind; `BindLevels(nil)` stops persisting. Without SettingsKit it refuses at the caller.
- Added `LogKit:SetLimits(limits)` and `LogKit:GetLimits()` over `journalCapacity` (1024, an integer up to 65536 and at most SignalKit's `maxJournalCapacity`; `UNBOUNDED` refused because the ring is preallocated; changing it re-creates the journal keeping the newest entries that fit), `maxSinks` (16), `maxMessageLength` (1024 bytes, at least 16; longer messages are cut and marked with `...`, never inside a UTF-8 sequence) and `maxLoggers` (256); the last three accept `LogKit.UNBOUNDED`. Values are validated at the caller before anything changes; the limits are shared by every consumer in the session.
- Records are stamped with `GetTimePreciseSec()`; on a host without it `time` is `false`.
- Package state, loggers, levels, sinks, the journal, `LEVELS` and the `UNBOUNDED` sentinel survive an in-place upgrade through `Registry:Bootstrap`; slash-command handlers dispatch through package state, so a newer revision replaces their behaviour.
- 144 specs: level gating, lazy formatting (a metatable-driven probe proves the arguments are never touched while disabled), bare messages with `%`, override precedence and `GetLevel` sources, journal ring order and filtering (nested walks, logging during a walk), sinks (function, table with `Write` looked up per call, removal of itself or another sink during a message, failing sink isolation, a raising error handler, a refused journal firing), the chat sink's output and colours, the secret placeholder, truncation, limits, the slash command (case, extra tokens, no logger created), the SettingsKit binding (one write per change), in-place upgrades, manifest agreement, error levels pinned for every argument failure, and allocation guards on a disabled call, an enabled call with a sink, and a history walk.
