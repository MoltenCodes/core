# CommandKit Tests

The CommandKit suite covers:

- `Parse_spec.lua`, parsing: whitespace runs, double and single quotes, the empty quoted token, escaped quotes (other backslashes kept), a hyperlink with spaces as one token, an item link as the only argument and among others, colour-wrapped text (and a colour without `|r` as ordinary text), textures and `||`, a hyperlink containing a quote inside a quoted token, single quotes read as apostrophes when they do not close before a boundary, adjacent segments joined, `\\` unescaped, an unclosed colour not swallowing text up to another colour's `|r`, a pipe that starts no escape sequence read as one ordinary byte (before whitespace and before a closing quote), unterminated double quotes and links refused with their reason, `ParseInto` filling an array, clearing leftover slots and emptying it on a refusal, `Parse` returning a new array per call, and non-string input;
- `Register_spec.lua`, registration: the two globals and the key for addon and manual scopes, a slash name taken by another addon (also through a second `SLASH_<key><n>` and through `SecureCmdList`) or another scope, a chat type's and an emote's slash name (and `MAXEMOTEINDEX` bounding the emote check), a second registration in one scope, `MAX_COMMANDS` and `"full"`, `Unregister` leaving an inert dispatcher and a later registration by another scope reusing the key, malformed names and specs (`arguments` without a handler included), the three-level depth bound, and a host without `SlashCmdList`;
- `Dispatch_spec.lua`, dispatch: every token passed to the handler with the command path and raw text, sub-commands three levels deep matched without case, generated usage and the unknown sub-command message, token conversion for number and boolean schemas, per-position refusals printing the SchemaKit failure and the usage (also for a missing argument and too many), the default of a missing `optional` position filled in, an array schema, an unterminated quote, a handler error isolated and reported to the sink and the host, the context methods, a context kept after its command refused, nested commands with their own contexts, the nesting bound, and `Printf` through LocaleKit's indexed specifiers;
- `Sink_spec.lua`, sinks: `DEFAULT_CHAT_FRAME` by default, `SetSink` and `SetSink(nil)`, `print` without a chat frame, `CaptureSink` copies, `Clear` and its 256-line bound, and a sink without `AddMessage`;
- `BindOptions_spec.lua`, `BindOptions` against a real OptionsKit tree bound to a SettingsKit-shaped database: generated usage, `get` of every kind, `set` of every kind (toggle words, a number, a select by key and by label, a colour in both forms, multiselect entries, joined input), a `validate` refusal message with nothing written, schema and parse refusals, `reset` to the default and refused without one, `list` of the root, a group and single options, `exec` with and without confirmation, unknown, hidden and disabled options, a missing path, a tree that is not a tree, and a host without OptionsKit;
- `Completion_spec.lua`, completion with a stubbed `ChatEdit_CustomTabPressed`: off until enabled, a unique sub-command, the common prefix and the candidate list, a custom `complete` function by position, bound option paths, forwarding of foreign text, `ChatEdit_GetActiveWindow` when no edit box is passed, restoring the previous function when the last scope disables completion, staying in a chain another addon built on top, a failing `complete` function, and a host without the extension point;
- `Scope_spec.lua`, scopes: `ForAddon` canonical, `Close` leaving an inert global with no output or error, terminal `Close` refusing registration and completion, `CloseAddonScopes` freeing the names and recording nothing for an addon without a scope, and dotted facade calls;
- `SecretValues_spec.lua`, secret values: `Print` and `Printf` (template included) refusing a secret at the handler, secret text and names refused with and without ClientKit, secret completion candidates and secret `SLASH_<key><n>` and `EMOTE<n>_CMD<m>` values skipped, and a secret option value shown as a placeholder;
- `Allocation_spec.lua`, allocation guards (`collectgarbage("count")` with the collector stopped) on `ParseInto` of a line with quotes and an item link, on a checked two-level sub-command dispatch, and on an inert dispatcher;
- `Bootstrap_spec.lua`, duplicate embedded loading, Registry publication, loading with Registry and SchemaKit alone, yielding to a newer revision, a missing Registry or SchemaKit, an incomplete facade, and an in-place upgrade to revision 2 that keeps commands, inert dispatchers and the completion replacement working;
- `ErrorLevels_spec.lua`, `error` levels: facade, scope and context argument failures and spec refusals several sub-commands deep all report the caller's own line;
- `Manifest_spec.lua`, manifest/runtime API and revision consistency.

The shared fixture does not model the chat host, so `support/CommandKitTestEnv.lua` installs `SlashCmdList`, a `DEFAULT_CHAT_FRAME` whose lines `ChatLines` returns, a counting `ChatEdit_CustomTabPressed` and `ChatEdit_GetActiveWindow`, a `ChatTypeInfo` with `SAY` (`/s`, `/say`) and `GUILD` (`/g`, `/guild`), and the emotes `/dance` and `/wave` (`/greet`) as `EMOTE<n>_CMD<m>`, and removes them again in `Reset` together with every `SLASH_*` and `EMOTE*_CMD*` global. `RunSlash(line)` does what the client does with a typed line: it finds the key whose `SLASH_<key><n>` matches and calls the slash function with the rest of the line. `NewEditBox` and `PressTab` drive completion.

OptionsKit, LocaleKit and ClientKit are declared under `optionalDependencies`, so the runner puts them on `LUA_PATH`. `NewPackage` loads Registry, SignalKit, SchemaKit, OptionsKit and CommandKit; `NewPackageWithLocaleKit` and `NewPackageWithClientKit` add one more; `NewPackageAlone` loads Registry, SchemaKit and CommandKit only. The `BindOptions` specs register a SettingsKit API 1 stand-in and a SettingsKit-shaped database so bound options and `Reset` can be exercised.
