# WidgetKit Tests

The WidgetKit suite covers:

- the type registry: the twelve base types at version 1, registration, a lower version ignored and an equal one reported, `unknownType`, acquire and release round trips, pooled reuse, `OnAcquire` and `OnRelease` on every cycle, stale-generation discard of pooled and borrowed widgets after a higher version, the frame cap (`exhausted`) and the cap raised by an upgrade, constructor results that break the author contract, a raising constructor and a raising `OnAcquire`, and argument validation;
- release: double release and foreign widgets refused, callbacks, user data, size requests and anchors cleared, re-parenting to `UIParent` or to the hidden holder without one, the order `OnRelease` callback, children last first, type hook, `IsReleasing` through an ancestor chain, release from inside a release refused, a failing hook reported, and focus cleared;
- the widget base: the shared prototypes, `Fire` arguments and isolated errors, the sixteen-callback cap, user data, size requests and methods forwarded to the frame, `SetParent`, and focus;
- layouts against the shared frame fixture, asserted through the anchors it records: `List` stacking, relative widths, `Fill`, `Flow` wrapping and full-height children, nested containers laid out top-down with heights reported upward, paused layout and no `OnSizeChanged` script, the recursion refusal, a raising layout, `beforeWidget` and moving children, the 256-child cap, `ReleaseChildren`, and custom layouts;
- anchors: the election of each of the nine points, ties in `POINTS` order, `FromRect` into a table without allocating, every `Normalize` argument form, the `Apply`/`Read` round trip, and an unknown relative frame;
- position bindings: an immediate save on drag, restore on bind, scaled frames, frames that are not positioned, unreadable saved anchors, release with the window; and, with SchedulerKit and SettingsKit loaded, a debounced save, `Flush` and release, and a SettingsKit scope view as storage;
- each base widget's behaviour and callbacks, including the client `ColorPickerFrame` path and key capture;
- secret values: text refused without `allowSecret`, a secret text never measured, pooled text cleared on release, and secrets refused where a widget would compare them;
- the renderer against a real OptionsKit tree with every kind: widget choice and order, hidden options skipped, values and hints shown, writes for every value kind, `validate` and schema refusals shown inline and cleared, disabled groups, `OnChange` refresh, rebuild when an option is shown or hidden, `execute` with `confirm`, release of everything together, secrets hidden or shown with `allowSecret`, layout of the whole tree, argument refusals, widget exhaustion, and the refusal without OptionsKit;
- media pickers with the real MediaKit, including a rendered `select` bound to SettingsKit, and the behaviour without MediaKit;
- allocation guards (`collectgarbage("count")` with the collector stopped) on warm acquire/release cycles, on `PerformLayout` with unchanged children for every layout, and on `Fire`;
- duplicate embedded loading, Registry publication, each missing required dependency, an incomplete facade, yielding to a newer revision, an in-place upgrade to revision 2 keeping live widgets, and a newer copy raising a base widget's version;
- `error` levels: facade, widget, container, widget-type, anchor, binding and rendering errors report the caller's own line;
- manifest/runtime API and revision consistency, and the position of `optionalDependencies`.

`support/WidgetKitTestEnv.lua` loads Registry, SignalKit, PoolKit, SchemaKit, OptionsKit and WidgetKit on the shared fixture and creates `UIParent` (1920 x 1080 at the origin); it adds `InstallSecretProbe` / `NewSecret`, `AllocatedKilobytes`, `LoadRevision`, and loaders without OptionsKit and without `UIParent`. `support/WidgetKitHostTestEnv.lua` also loads EventKit, LifecycleKit, TimerKit, SchedulerKit, SettingsKit and MediaKit, removes the saved variables a spec opens, and fires the latest native timer for debounced saves. OptionsKit, SettingsKit, SchedulerKit and MediaKit are declared under `optionalDependencies`, so the runner puts them and their closures on `LUA_PATH`.

The fixture's `FrameStub` resolves a frame's rect from its anchors, so `GetWidth`, `GetHeight` and `GetRect` answer as the client would for one anchor (the frame's own size) and for two anchors on opposite edges (the size they span). It does not model text wrapping (a string is 6 pixels per byte and 12 per line), scale in geometry, or strata.
