# WidgetKit Tests

The WidgetKit suite covers:

- the type registry: the twelve base types at their versions (3, `ScrollFrame` and `Spacer` 1), registration, a lower version ignored and an equal one reported, `unknownType`, acquire and release round trips, pooled reuse, `OnAcquire` and `OnRelease` on every cycle, stale-generation discard of pooled and borrowed widgets after a higher version, the frame cap (`exhausted`), the cap raised by one retired generation per upgrade and clamped to 4096 over repeated upgrades, constructor results that break the author contract, a raising constructor and a raising `OnAcquire`, and argument validation;
- release: double release and foreign widgets refused, callbacks, user data, size requests and anchors cleared, re-parenting to `UIParent` or to the hidden holder without one, the order `OnRelease` callback, children last first, then the type hook, `IsReleasing` through an ancestor chain, release from inside a release refused, `AddChild` and `AddChildren` refused while the container or the child is being released, `Fire`, `GetType`, `IsReleasing` and `Release` refused on a non-widget, a failing hook reported, and focus cleared;
- the widget base: the shared prototypes, `Fire` arguments and isolated errors, the sixteen-callback cap, user data, size requests and methods forwarded to the frame, `SetParent`, and focus;
- layouts against the shared frame fixture, asserted through the anchors it records: `List` stacking, relative widths, `Fill`, `Flow` wrapping and full-height children, nested containers laid out top-down with heights reported upward, paused layout and no `OnSizeChanged` script, the recursion refusal (also from an `OnLayoutStart` hook), the depth refusal at 32, a raising layout, `beforeWidget` and moving children, the 256-child cap, `ReleaseChildren`, custom layouts, a `Flow` row filled exactly by relative widths, and content narrower than nothing;
- anchors: the election of each of the nine points, ties in `POINTS` order, `FromRect` into a table without allocating, every `Normalize` argument form, the `Apply`/`Read` round trip, an unknown relative frame, a frame the current code may not touch, and malformed anchors, relative frames (a secret one included) and `into` tables refused at the caller;
- position bindings: an immediate save on drag, restore on bind, scaled frames, frames that are not positioned, unreadable saved anchors, release with the window, the default scale back on the next use of a window; and, with SchedulerKit and SettingsKit loaded, a debounced save, `Flush` and release, and a SettingsKit scope view as storage;
- each base widget's behaviour and callbacks, including the client `ColorPickerFrame` path, its callbacks disarmed by a release and the stored alpha kept, key capture (with ALT, CTRL and SHIFT, and turned off without a callback), a refused `SetList` leaving the entries alone, the base `SetDisabled` of `Frame`, `ScrollFrame` and `Spacer`, `SetMovable`, `SetJustifyH`, `SetMaxLetters`, leaving tri-state, the argument refusals of the setters, and the dropdown list on `UIParent` with the outside-click catcher;
- secret values: text refused without `allowSecret`, an `EditBox` text refused even with it, a secret text never measured and a measurement the client answers as a secret never handed to `SetHeight`, a secret text shown on a font string of its own in every text slot so the font string that shows plain texts never holds one (`SecretTexts_spec.lua`: the next use of a `Label` that showed a secret measures a plain text, within one use too; one secret font string per slot over fifty secret cycles; anchors, font, justification, colour and wrap moving with the text; a `Heading`'s lines, a `Button`'s font and a `Group`'s content following it), a secret `SetLimits` value refused with the secret message, and secrets refused where a widget would compare them, counts and indices included, before any comparison with a word, `nil` or the sentinel (`SetJustifyH`, user-data keys, an optional `alpha` or relative width, caps and limits);
- rendering ownership: release with the container (directly and through an ancestor), no writes into a re-acquired widget, `Release` after the container is gone, a rendered widget stolen and re-acquired, a raising `validate`, a raising build that resumes the container, and confirmation disarm and text (also after five seconds with SchedulerKit);
- the renderer against a real OptionsKit tree with every kind: widget choice and order, hidden options skipped, values and hints shown, writes for every value kind, `validate` and schema refusals shown inline and cleared, disabled groups, `OnChange` refresh, rebuild when an option is shown or hidden, `execute` with `confirm`, release of everything together, secrets hidden or shown with `allowSecret`, layout of the whole tree, argument refusals (malformed `allowSecret` and `media` included), widget exhaustion, and the refusal without OptionsKit;
- media pickers with the real MediaKit, including a rendered `select` bound to SettingsKit, a MediaKit list longer than `maxDropdownEntries` refused without borrowing a `Dropdown`, and the behaviour without MediaKit;
- allocation guards (`collectgarbage("count")` with the collector stopped) on warm acquire/release cycles, on `PerformLayout` with unchanged children for every layout, and on `Fire`;
- duplicate embedded loading, Registry publication, each missing required dependency, an incomplete facade, yielding to a newer revision, an in-place upgrade to the next revision keeping live widgets, an upgrade of a revision 1, 2, 3 and 4 copy by the current file (the revision 4 container laid out with a secret content width afterwards), an upgrade of a revision 5 copy whose base types were at version 1 (ten raised: pooled widgets discarded, borrowed ones kept until released, `ScrollFrame` reused), an upgrade of a revision 6 copy whose base types were at version 2 (a pooled `Label` whose font string showed a secret retired, the next one measuring its text), and a newer copy raising a base widget's version;
- `error` levels: facade, widget, container, widget-type, anchor, binding and rendering errors report the caller's own line;
- the client's frame scripts, run by the fixture rather than by hand: a dropdown list closed from `OnHide` once per real hide, WidgetKit's focus following the edit focus between two edit boxes and no focus-lost script for a box without the focus, every base widget laid out in every layout inside nested containers without an anchor to itself or a cycle, and the client's anchor refusals passed on (`FrameScripts_spec.lua`);
- limits: the default `maxCreatedCeiling`, a raised ceiling honoured by registrations and upgrades, a lowered ceiling keeping caps already given, `UNBOUNDED` refused for frames at the caller's line, invalid and unknown limits refused without changing anything (a table key named by its type without running its `__tostring`), `maxCallbacks` including `UNBOUNDED`, `maxDropdownEntries` at its default, raised, lowered and `UNBOUNDED` with the row frames staying at the visible set, invalid values refused at the caller's line, `SetMaxChildren` including `UNBOUNDED` and its reset on release, and the sentinel, the limits and opened bounds kept across an in-place upgrade;
- the client's behaviour measured on Retail 12.1.0 b69933 on 2026-09-25 (`ClientRules_spec.lua`): the fixture's client rules themselves, every text getter answering `""` where the client answers `nil`, a `Frame` window keeping the `DIALOG` strata under a `MEDIUM` parent and on reuse, a `Label`'s font string wrapping at the label's own width (at `Create`, from `SetWidth` and from a layout), and a secret measurement of a label never reaching `SetHeight`;
- manifest/runtime API and revision consistency, and the position of `optionalDependencies`.

`support/WidgetKitTestEnv.lua` loads Registry, SignalKit, PoolKit, SchemaKit, OptionsKit and WidgetKit on the shared fixture and creates `UIParent` (1920 x 1080 at the origin); it adds `InstallSecretProbe` / `NewSecret`, `AllocatedKilobytes`, `LoadRevision`, `InstallClientRules`, and loaders without OptionsKit and without `UIParent`. `support/WidgetKitClientRules.lua` holds the client rules every loader of both environments installs, each measured in the client: `SetWidth`, `SetHeight`, `SetSize` and `SetPoint` of a frame or font string, and `SetText` of an edit box, raise the client's message (`bad argument #1 to 'SetHeight' (Usage: self:SetHeight(height). Secret values are only allowed during untainted execution for this argument.)`) at the caller's line when an argument is a value `issecretvalue` reports secret, so every spec proves WidgetKit never hands the client a secret there; a font string's or button's `GetText()` answers `nil` for an empty text; a font string that showed a secret keeps answering its text with that secret until `ClearText`, and its measurements for good (measured 2026-09-25, 11:09); a font string answers `GetJustifyH` and `CanWordWrap` with what its setters stored; and `SetParent` hands a frame its parent's strata unless `SetFixedFrameStrata(true)` was called. `support/WidgetKitHostTestEnv.lua` also loads TimerKit, SchedulerKit, SettingsKit and MediaKit, removes the saved variables a spec opens, and fires the latest native timer for debounced saves. OptionsKit, SettingsKit, SchedulerKit and MediaKit are declared under `optionalDependencies`, so the runner puts them and their closures on `LUA_PATH`.

The fixture's `FrameStub` resolves a frame's rect from its anchors, so `GetWidth`, `GetHeight` and `GetRect` answer as the client would for one anchor (the frame's own size) and for two anchors on opposite edges (the size they span). It fires `OnShow` / `OnHide` when a frame's own shown flag changes, moves the edit focus between edit boxes with their `OnEditFocusLost` / `OnEditFocusGained` scripts, and refuses an anchor to the region itself or one that closes an anchor cycle, as the client does. It does not model text wrapping (a string is 6 pixels per byte and 12 per line), scale in geometry, strata ordering (a frame only records its strata, which the client rules hand from parent to child on `SetParent`), or visibility scripts on children of a frame that changed.
